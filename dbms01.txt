DataBase
- SQL문장(Query) : 
	데이터베이스에게 "뭔가를 해줘"라고 요청하는 일종의 명령문이다

DML(Data Manipulation Language) : 데이터 조작어
 - insert, select, update, delete
C(Create)
R(Read)
U(Update)
D(Delete)

DDL(Data Definition Language) : 데이터 정의어
- create, akter, drop, rename 등등...

DCL(Data Control Language) : 데이터 제어어
- grant, revoke

1) SQL 자료형
- number : 숫자 데이터를 저장하기 위한 자료형
- date : 날짜와 시간 데이터를 저장하기 위한 자료형
- char : 문자 혹은 문장 데이터를 저장하기 위한 자료형
- varchar2 : 문자 혹은 문장 데이터를 저장하기 위한 자료형
- CLOB : 대용량의 문장을 저장하기 위한 자료형

2) Start Database로 query문 입력해서 test 계정에 권한주기
 1. 시스템 계정으로 로그인하기
	sqlplus system/1111
 2. test 계정에 권한을 주기
	grant connect, resource, dba to test;
 3. test 계정 잠금 해제
	alter user TEST identified by 1111 account unlock;
