1. SQL(Query)문이란?
데이터 베이스에 있는 정보를 꺼내오게 요청하는 명령문

2. DML, DCL, DDL에 대해서 설명하시오.
DML(Data Manipulation Language)은 데이터 조작어이고 insert, select, update, delete가 있다. insert는 Create, select는 Read, update는 Update, delete는 Delete가 된다.

DDL(Data Definition Language)은 데이터 정의어이고 alter, 	create, drop, rename 등등이 있다. 
create은 테이블을 생성할 때 	사용한다. -> create table kh()
alter는 테이블 안에 있는 컬럼들을 변경할 때 사용한다.
-> alter table kh add birth DATE;
drop은 테이블이나 컬럼을 삭제할 때 사용한다.
rename은 컬럼명을 변경할 때 사용한다.
modify는 컬럼 속성을 변경할 때 사용한다.

DCL(Data Control Language)은 데이터 제어어이고 grant와 revoke가 있다.

3. OracleDB 자료형의 종류를 서술하세요.
number : 숫자를 저장하기 위한 자료형이다.
date : 날짜와 시간을 저장하기 위한 자료형이다.
char : 문자와 문장을 저장하기 위한 자료형이다.
varchar2 : 문자와 문장을 저장하기 위한 자료형이다.
clob : 대용량의 문장을 저장하기 위한 자료형이다.

4. LIKE에 대해서 설명하시오.
사용자가 검색할 때 포함되어 있는 데이터를 찾아준다.
%와 _가 있다. %는 모든 값을 찾아주고 _는 하나의 값을 찾아준다.

5. IN과 BETWEEN의 차이를 설명
IN은 or과 비슷하다고 볼 수 있고 BETWEEN은 and와 비슷하다.
IN은 따로따로 데이터를 가져오고 BETWEEN은 사이의 데이터를 가져와준다.
	
6. id, pwd, name, email, phone을 저장하는 회원테이블(member_t)를 만드는 Query를 작성. 
단, id와 기본키로 지정하도록 하며, pwd와 name은 null값을 허용하지 않도록 한다.

	id number(3) primary key,
